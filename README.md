# File Organizer 🗂️

An automated file management tool designed to clean up messy directories. It inspects each file's format/extension and moves it to its designated folder.

### Key Features
- **Smart Sorting:** Automatically categorizes files (e.g., `.png`/`.jpg` → `Images`, `.pdf`/`.docx` → `Documents`, more to come...).
- **Customizable Rules:** Define your own folder mappings and target extensions.
- **Fast & Lightweight:** Processes hundreds of files in seconds without bloat.
